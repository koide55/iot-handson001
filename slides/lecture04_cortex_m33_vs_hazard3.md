# 第4回 発展: Cortex-M33 と Hazard3 を比べる

## この資料の目的

この資料は、`Raspberry Pi Pico 2 W` 上で選べる 2 つの CPU 系統

- `ARM Cortex-M33`
- `RISC-V Hazard3`

を、**同じ題材で比べるための発展資料** です。

ここでは「どちらが優れているか」を決めるのではなく、

- 同じ処理を
- 別の ISA で
- どう表現するか

を見ることが目的です。

---

## 比較の前提

`RP2350` では、Arduino IDE の `Tools -> CPU Architecture` で

- `ARM Cortex-M33`
- `RISC-V Hazard3`

を切り替えられます。

どちらも **32 ビット** です。ただし、命令体系は異なります。

---

## まず結論

### 最初に学びやすいのは

- `Cortex-M33`

理由:

- `CBZ`
- `UBFX`
- `BFI`
- `RBIT`
- `REV`
- `CLZ`

のように、教材化しやすい専用命令があるからです。

### 比較すると面白いのは

- `Hazard3 RISC-V`

理由:

- 同じことをもっと素朴な命令の組み合わせで書く場面が見えやすい
- ISA の思想の違いを感じやすい

---

## 今回の比較テーマ

今回は、同じ `LED 反転` を題材にします。

比較する観点:

1. 定数 `1` をどう作るか
2. 状態をどう読むか
3. bit 0 をどう反転するか
4. 関数からどう戻るか

---

## Cortex-M33 側の見え方

たとえば、今回の資料で使った反転関数は次のような形です。

```asm
ldr r1, [r0]
movs r2, #1
eors r1, r1, r2
str r1, [r0]
bx lr
```

読むときのポイント:

- `ldr`
  - 読む
- `movs`
  - 定数 `1`
- `eors`
  - bit 0 を反転
- `str`
  - 書き戻す
- `bx lr`
  - 戻る

かなり「手続きの流れ」がそのまま見えます。

---

## Hazard3 RISC-V 側の見え方

同じ考え方を RISC-V 風に書くと、次のようなイメージになります。

```asm
lw   a1, 0(a0)
li   a2, 1
xor  a1, a1, a2
sw   a1, 0(a0)
ret
```

読むときのポイント:

- `lw`
  - 読む
- `li`
  - 定数 `1`
- `xor`
  - bit 0 を反転
- `sw`
  - 書き戻す
- `ret`
  - 戻る

こちらも流れは似ていますが、命令名やレジスタ名の文化が違います。

---

## 並べて見る

| 役割 | Cortex-M33 | Hazard3 RISC-V |
|---|---|---|
| 読む | `ldr` | `lw` |
| 定数 `1` | `movs` | `li` |
| 反転 | `eors` | `xor` |
| 書く | `str` | `sw` |
| 戻る | `bx lr` | `ret` |

この表を見ると、**やりたいことは同じだが、書き方の流儀が違う** ことが分かります。

---

## どこが面白いか

### Cortex-M33 の面白さ

- ビット操作に強い専用命令が多い
- マイコン向けの「気の利いた命令」が多い

### Hazard3 RISC-V の面白さ

- より素朴で、命令の役割がまっすぐ見える
- 「なぜ ARM に専用命令があるのか」が逆に見えてくる

---

## 発展ハンズオン

### ねらい

同じ `LED 反転` を、`Cortex-M33` と `Hazard3` で見比べて、ISA の違いを言葉にできるようにします。

### 前提

- まず `Cortex-M33` 版の穴埋め演習を終えていること
- `Tools -> CPU Architecture` を切り替えられること

### ハンズオン内容

1. `Cortex-M33` 版の `led_toggle_asm()` を見直す
2. `Hazard3` ならどんな命令列になりそうか、紙やコメントで書く
3. 次の 5 点を比較する

- 読む命令
- 定数を作る命令
- 反転命令
- 書く命令
- 戻る命令

### ここでの注意

この資料では、`Hazard3` 用の完全な `.S` プロジェクトはまだ配布していません。まずは **比較して説明できること** を目標にします。

## まとめ

今回の比較で大事なのは、次の点です。

- `Cortex-M33` は専用命令が多く、教材として扱いやすい
- `Hazard3 RISC-V` は素朴で、比較対象として面白い
- 同じ LED 反転でも、命令体系ごとの流儀が見える

本編の授業では `Cortex-M33` を主役にし、発展として `Hazard3` を比べると、学習効果が高くなります。
