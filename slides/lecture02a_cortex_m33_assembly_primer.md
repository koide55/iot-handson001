# 第2.5回 Cortex-M33 アセンブラ超入門

## 2. まずレジスタとは何か

レジスタは、CPU の中にあるとても小さくて速い記憶場所です。

今回の `Cortex-M33` では、たとえば次の名前が出てきます。

- `r0`
- `r1`
- `r2`

イメージとしては、CPU の手元にある作業メモのようなものです。

### 今回の演習での使い方

- `r0`
  - 関数に渡された値やアドレスが最初に入る
- `r1`
  - 読み出した値を入れる
- `r2`
  - 定数 `1` のような補助値を入れる

---

## 3. アドレスと中身は違う

ここは最重要です。

たとえば `r0` に入っているのが `state` の**アドレス**だとします。

これは「`state` そのもの」ではなく、「`state` が置かれている場所」を表しています。

たとえると、

- アドレス
  - ロッカーの番号
- 中身
  - ロッカーの中に入っているもの

の違いです。

---

## 4. `ldr` と `str`

### `ldr`

`ldr` は、メモリから値を読む命令です。

```asm
ldr r1, [r0]
```

これは、

- `r0` に入っているアドレスを見に行く
- その場所の値を読む
- 読んだ値を `r1` に入れる

という意味です。

### `str`

`str` は、メモリへ値を書く命令です。

```asm
str r1, [r0]
```

これは、

- `r1` の値を
- `r0` に入っているアドレスの場所へ書き戻す

という意味です。

### 2 つ合わせると

```asm
ldr r1, [r0]
... r1 を加工する ...
str r1, [r0]
```

で、

1. 読む
2. 加工する
3. 書き戻す

という基本パターンになります。これを **read-modify-write** と呼びます。

---

## 5. `movs`

`movs` は、値をレジスタへ入れる命令です。

```asm
movs r2, #1
```

これは、`r2 = 1` に近い意味です。

今回の演習では、

- bit 0 だけを立てたい
- bit 0 だけを反転したい

ので、`1` をマスクとしてよく使います。

---

## 6. bit 0 とは何か

2 進数では、右端のビットが bit 0 です。

たとえば `1` は次の形です。

```text
00000001
```

つまり、**bit 0 だけが 1** です。

これをマスクとして使うと、

- bit 0 だけを立てる
- bit 0 だけを消す
- bit 0 だけを反転する

ことができます。

---

## 7. `orrs`

`orrs` は OR 演算です。

```asm
orrs r1, r1, r2
```

これは、だいたい

```c
r1 = r1 | r2;
```

と同じです。

### OR のイメージ

- `0 | 1 = 1`
- `1 | 1 = 1`

なので、マスク `1` を使うと **bit 0 を立てる** のに向いています。

### LED ON での意味

`state` の bit 0 を 1 にすれば、LED を ON とみなせます。

---

## 8. `bics`

`bics` は「指定したビットを落とす」方向で使う命令です。

```asm
bics r1, r1, r2
```

今回の感覚としては、

```c
r1 = r1 & ~r2;
```

に近いと思ってください。

### 何がうれしいか

`r2 = 1` なら、bit 0 だけを 0 にできます。

### LED OFF での意味

`state` の bit 0 を 0 にすれば、LED を OFF とみなせます。

---

## 9. `eors`

`eors` は XOR 演算です。

```asm
eors r1, r1, r2
```

これは、

```c
r1 = r1 ^ r2;
```

に近いです。

### XOR のイメージ

- `0 ^ 1 = 1`
- `1 ^ 1 = 0`

つまり、**同じ 1 をもう一度当てると反転する** のがポイントです。

### LED TOGGLE での意味

`state ^= 1` に相当するので、bit 0 を ON / OFF ひっくり返せます。

---

## 10. `cbz`

`cbz` は Compare and Branch on Zero です。

```asm
cbz r0, .Lpressed
```

これは、

- `r0` が 0 なら
- `.Lpressed` へ飛ぶ

という意味です。

### C で近い形

```c
if (r0 == 0) {
  goto pressed;
}
```

### 今回のボタン回路での意味

`INPUT_PULLUP` なので、

- 押していない: `1`
- 押した: `0`

です。したがって、`0` のときに飛ぶ `cbz` がぴったりです。

---

## 11. `ubfx`

`ubfx` は unsigned bit-field extract、つまり **ビットの一部分を抜き出す** 命令です。

```asm
ubfx r0, r0, #4, #2
```

これは、

- `r0` の bit 4 から
- 2 bit 取り出して
- 結果を `r0` に入れる

という意味です。

### C で近い形

```c
r0 = (r0 >> 4) & 0x3;
```

---

## 12. `bfi`

`bfi` は bit-field insert、つまり **ビットの一部分へ値を埋め込む** 命令です。

```asm
bfi r0, r1, #4, #2
```

これは、

- `r1` の下位 2 bit を
- `r0` の bit 4 からの位置に埋め込む

という意味です。

### C で近い形

```c
r0 = (r0 & ~(0x3 << 4)) | ((r1 & 0x3) << 4);
```

---

## 13. `rbit`

`rbit` は bit reverse、つまり **ビット順を反転** します。

```asm
rbit r0, r0
```

たとえば右端にあった 1 が、左端側へ移るようなイメージです。

これは手でやると大変なので、専用命令のありがたさが分かりやすい例です。

---

## 14. `rev`

`rev` は reverse、ここでは **バイト順の反転** です。

```asm
rev r0, r0
```

たとえば、

```text
0x12345678 -> 0x78563412
```

のようになります。

---

## 15. `clz`

`clz` は count leading zeros、つまり **先頭の 0 の個数を数える** 命令です。

```asm
clz r0, r0
```

たとえば値が小さいほど、左側に 0 がたくさん並ぶので `clz` の結果は大きくなります。

---

## 16. `bx lr`

`bx lr` は関数から戻る命令です。

今回の演習では、「最後に呼び出し元へ戻る」と覚えれば十分です。

```asm
bx lr
```

ほぼ「return」のつもりで読んで構いません。

---
