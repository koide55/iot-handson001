# IoT Hands-On Materials

This directory contains Markdown-first lecture materials rebuilt from the original PDF handout.

## Scope

- Target board: Raspberry Pi Pico 2 W with headers
- Sensors: BMP280 + AHT20
- Output format: Markdown
- Included:
  - environment setup
  - microcontroller basics
  - GPIO exercises
  - I2C sensor exercises
  - Wi-Fi connection
  - Ambient visualization
  - Cortex-M33 assembly slides
  - Cortex-M33 assembly minimal project
- Excluded:
  - Arpspoof exercise
  - ARM64 / Linux assembly exercise
